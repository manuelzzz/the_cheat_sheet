# Project

## Overview

The Cheat Sheet is an open-source collection of practical cheat sheets for developers.

Content is stored as Markdown files in the repository and automatically rendered as pages on the website.

Anyone can contribute by adding or improving a Markdown file through a Pull Request.

## Core Principle

> A folder defines structure. A Markdown file defines content. A Pull Request is a contribution.

## Goals

The project should:

- Make developer knowledge easy to discover.
- Be easy to contribute to.
- Keep content inside the repository.
- Avoid unnecessary infrastructure.
- Support community-driven translations.

## Non-Goals

The project should not require:

- A database.
- A backend API.
- Authentication.
- User accounts.
- A CMS.

These should not be introduced without a clear project requirement.
